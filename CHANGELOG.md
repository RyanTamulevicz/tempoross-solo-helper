# Changelog

This project follows [semantic versioning](https://semver.org/). The version shown on the Plugin Hub comes from `runelite-plugin.properties`.

## 1.1.0

- Add the **Cooking + firefighting (max permits)** method from the OSRS Wiki (17/19/19/2 route).
- Show storm intensity on the panel for the max permits deadline and firefighting steps.
- Track partial cannon loads forced by the storm and guide the player to finish the shortfall.
- Add a douse-fire target that highlights the nearest fire, including on the ship.
- Read the build version from `runelite-plugin.properties`.

## 1.0.0

- Initial Plugin Hub release with the **No cooking (max XP)** and **Cooking Mix of XP and permits** methods.
